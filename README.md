# image-cli

Exocortex external tool for OpenAI-backed raster image generation.

## Usage

```bash
printf '%s' 'a tiny red square icon' | image generate
```

`image generate` reads the exact UTF-8 prompt from stdin. Inline prompt
arguments are rejected. Use `--out PATH` to choose the output path and
`--json` for structured output.

The image is generated by exocortexd with its own OpenAI login: the tool sends
the prompt over the daemon socket (`EXOCORTEX_SOCKET`, else the checkout's
`config/runtime/exocortexd.sock`) and saves the returned bytes. It never sees a
credential, and it works from any shell, including Claude Code's.
